## Open the website locally

Open `index.html` in any modern browser. Use the project cards to open `samples.html`, which presents the three work samples. No build tools, accounts, or dependencies are required.

## Publish with GitHub Pages

1. Sign into GitHub as `alliethompson1989-cell`.
2. Create a **new public repository** named `Portfolio` (leave the optional initial README unchecked).
3. Upload the **contents of this folder**, not the ZIP file itself. Make sure `index.html` is in the repository's top level.
4. Commit the files to the `main` branch.
5. Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
6. The site can be accessed at `https://alliethompson1989-cell.github.io/Portfolio/` once GitHub finishes publishing it.

If you would prefer a GitHub profile README instead of a separate site, create a repository named exactly `alliethompson1989-cell` and use this page's overview as its README.
