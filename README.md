## How I work

- **Investigate:** Look at records, configuration, permissions, user workflows, and integrations before settling on a root cause.
- **Validate:** Define expected behavior, build repeatable checks, and separate evidence from assumptions.
- **Communicate:** Write clear issue reports and documentation that teams can actually use.
- **Improve:** Look for recurring patterns that suggest a systemic fix, better testing, or clearer processes.
